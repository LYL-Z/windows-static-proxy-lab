# 账户安全与服务资格（ACCOUNT-SECURITY）

## 1. 结论先行

**Claude 专项状态：`NOT_READY`。**

理由不是网络问题，而是**资格问题**。V2 阶段已独立核验 Anthropic 官方页面（抓取于 2026-11-18，只读），事实如下：

| 事实 | 官方依据 |
|---|---|
| 存在正式的 **Supported Regions Policy**，2026-11-12 生效 | anthropic.com/legal/supported-regions |
| 政策是**封闭清单**：未列出的国家/地区即"不支持" | 同上 |
| **中国大陆不在清单内** | 同上；帮助中心清单亦不含 |
| 资格以**人身实际所在位置**判定，是三条并列门槛之一 | "Use by persons while physically located in an unsupported region…" |
| Usage Policy 禁止"违反 Supported Regions Policy 访问或为他人提供访问" | anthropic.com/legal/aup |
| Consumer Terms 要求账号资料真实完整，并禁止"bypassing any of our systems or protective measures" | anthropic.com/legal/consumer-terms |
| 申诉入口需登录被封账号 | claude.ai/restricted（support.claude.com 有说明） |
| VPN / 住宅代理 | **官方文本未提及**；政策从未把 IP 作为资格标准，也未认可更换出口即可获得资格 |

**因此：**

- 美国静态 IP **不是**资格条件，也不是合规手段；
- "出口 IP 检测 100 分"**不能**替代资格判断；
- 第三方网站的"Claude 信任评分"**不是** Anthropic 的账号信用分，两者没有任何映射关系；
- 不应把任何第三方评分换算成"封禁概率"。

## 3. 订阅与资金风险（只陈述事实，不构成建议购买）

- 若实际使用资格不满足，**付费订阅存在"付费后无法稳定使用"的风险**；
- 是否可退款、退款窗口多久，取决于官方条款与购买渠道，**需要在下单前确认**；
- 本任务**不会**代为购买、续费、退款或注册任何账号；
- 已有的代理服务（NexIP）与 Claude 订阅是**两件独立的事**：前者解决"网络出口"，后者解决"服务资格"，不能互相抵扣。

## 5. 本项目的边界（明确不做）

- 不自动注册、登录、支付、退款；
- 不伪造身份、位置、设备指纹或支付资料；
- 不设计"让平台误判实际所在地"的方案；
- 不绕过地区限制、账号处置或身份验证；
- 不把"网络层跑通"包装成"服务已获授权"。

## 6. 如果用户决定继续

如果用户确认自己符合使用资格（例如实际身处支持地区），那么本项目的网络成果可以直接复用；否则应停止 Claude 方向的接入验收，把 NexIP 用在**不违反任何服务条款**的通用用途上（例如一般的国际网络访问、公开数据采集等，仍需遵守目标站点条款）。
