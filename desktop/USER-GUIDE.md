# 网络代理医生 1.2

Windows Proxy Doctor Desktop 和 Windows Proxy Doctor Skill 使用同一套故障分类。只读检查不会修改系统代理、防火墙或已安装的客户端。

恢复页的“确认后执行隔离演练”会先弹确认框，逐项列出操作名、目标（例如 `127.0.0.1:7897`）、操作范围、受影响资源、是否写系统代理和回滚方式；点“我确认，执行隔离演练”才算这次授权，点“取消（只做只读诊断）”等于拒绝，之后仍可只做只读诊断。确认后只运行哈希相符的 `rollback-v4.ps1`。测试模式不是操作系统沙箱。退出码 32 只是这次场景的预期。完整成功还要求配置哈希恢复、隔离写入只有关闭、事务日志清除，以及当前用户代理指纹不变。缺任何一项都不会显示成成功。这个结果不表示 StarSky 加速已经恢复。没有找到当前版本的官方重连接口，程序不会代你重启客户端。真实生产写入未实现：Executor 固定 `V4_TEST_MODE` + stub，不会写真实系统代理。

“预览方案”不启动脚本。记录或清除“我关闭了代理”只写本程序自己的文件。

监测页把本地心跳、上游 HTTPS 和人工协议检查分开。本地心跳不覆盖上一次 HTTPS。监听读取不完整时不会显示成端口已关闭。监测抛错时会标明失败，而不是继续沿用上一次正常。

## 打开

发布目录里的 `ProxyDoctor.exe` 用当前用户权限启动。托盘图标可以打开窗口、再做一次只读检查，或退出。退出后不应留下本程序的后台进程。

勾选“演示数据”时，界面上的内容是固定样例，并会标明不是这台电脑的实时结果。

## 读结果

`Aligned` 只表示系统代理选择和本地监听一致。它不表示网页或桌面程序已经走通代理。

`UserOff` 表示代理关闭。程序不会建议把它重新打开。

HTTPS 卡片记录的是 .NET 默认代理路径的状态码和耗时，不是整机保护证明。

隐私页里的“未验证”和“部分”是能力边界，不是检测页面的颜色。

## 安装与卸载

便携目录可以复制到任意文件夹。卸载时删除该文件夹。本程序不写启动项，不改系统代理。安装包没有代码签名。
