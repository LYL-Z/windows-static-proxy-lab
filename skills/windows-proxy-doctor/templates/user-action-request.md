# 用户操作请求

| 字段 | 内容 |
| --- | --- |
| 当前步骤 | 说明流程位置和现有证据。 |
| 为什么需要 | 说明哪项检查或流程目前需要用户操作。 |
| 具体动作 | 填写软件、页面位置、按钮文字、动作范围和预期状态。 |
| 费用或权限 | 列明付费可能性、预计权限及核实来源。遇到可选邀请时写明潜在受益方，列出普通入口。 |
| 完成信号 | 指出可核实的界面或运行结果，约定用户用文字确认，无需提供凭据。 |
| 拒绝、失败或回退 | 说明只读诊断如何继续、需要保存何种证据，以及获准回退时的步骤。 |
| Agent 可以协助什么 | 列出本会话实际可用工具及各自范围。注册、身份验证、付费和凭据留给用户。 |
