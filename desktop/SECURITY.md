# 安全说明

程序以当前用户身份运行，清单要求 `asInvoker`。

只读检查会读取当前用户的代理开关、代理服务器是否为两个本机回环地址之一、Clash 配置里的系统代理开关，以及本机回环端口的监听进程名。它不读取或显示代理口令。

任意 `127.0.0.1` 端口会按原样显示。其他地址显示 `TARGET_OTHER`。多个 `verge-mihomo` 监听只在与当前代理端口一致时才认作核心，否则不猜测。

恢复命令比较固定授权文字，然后启动固定的 `Invoke-IsolatedRecovery.ps1`。用户输入不会拼进 PowerShell。脚本要求工作目录位于 TEMP，并在库文件末尾拒绝非测试模式。测试模式的代理写入进入临时文件，不进入 HKCU。执行前后比较 `ProxyEnable` 和 `ProxyServer`。

写入当前 Windows 代理、防火墙、DNS、IPv6、TUN、路由或重启客户端，仍要按仓库部署说明单独授权。

发布文件没有 Authenticode 签名。校验应使用同一次发布生成的 SHA-256，而不是签名。
