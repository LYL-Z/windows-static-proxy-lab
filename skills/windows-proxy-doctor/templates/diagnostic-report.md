# 诊断报告

| 项目 | 记录 |
| --- | --- |
| 当前步骤与目标 | 说明只读检查、设置准备、授权待定、验证或回退。 |
| 现象、时间与范围 | 使用时区和可共享的目标标签，记录哪些应用受影响。 |
| 对照与现状 | 分别记录保存意图、Windows 当前生效路径、监听归属、第一跳及目标路径。 |
| 证据类别 | 标记用户观察、当前现场实测、隔离或合成测试。 |
| 失败阶段与结果 | 记录必要的 DNS、CONNECT、TLS、HTTP 或 UDP 观测及错误码，标记未知项。 |
| 可能原因与可信度 | 给出支持及不足的证据，不凭时间关联确认写入者。 |
| 处理或回退 | 说明实际做了什么，用户是否授权，以及验证结果。 |

## 供应商工单草稿

- 客户端和系统版本、故障时刻及时区。
- 脱敏后的复现步骤、目标标签、预期结果与实际结果。
- 测试路径、出现错误的阶段、响应码和对照结果。
- 请供应商核对的行为与希望收到的技术答复。

工单供用户审阅。共享前移除账号、订单、凭据、真实私有网络细节、可识别个人的路径和配置正文。
