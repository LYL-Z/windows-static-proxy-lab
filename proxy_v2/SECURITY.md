# 安全说明（SECURITY）

## 1. 凭据：硬事实与残余风险

**必须承认的硬事实**：Mihomo 的 `socks5` / `http` 节点只能以**明文**保存用户名密码（`username:` / `password:` 字段）。这是内核配置格式决定的，不是本工具的选择。因此：

- `profiles\LWMoQxn0PeIP.yaml` 与 `clash-verge.yaml` 中**必然**存在明文密码；
- 任何以当前用户身份运行的进程、以及本机管理员，**都能读到它**；
- 备份目录中的副本同样含明文。

本工具集能做的是把"凭据暴露面"压到最小，而不是假装它不存在。

## 2. 已实施的凭据保护

| 措施 | 实现位置 | 说明 |
|---|---|---|
| 凭据不落命令行 | 全部脚本 | 密码只从已有 profile 读取，从不作为参数传入；避免出现在进程列表与命令历史 |
| 日志强制脱敏 | `Register-Secret` + `Get-Redacted` | 所有 `Write-Log` 输出都过一遍脱敏；额外通用规则覆盖 `password=...`、`Basic <base64>` |
| 不回显 | `Get-ProfileCredential` | 只返回对象，日志仅打印 `user_len` / `pass_len` |
| 证据文件不含凭据 | `validate-v2` / `benchmark` / `monitor-v2` | 只记录 IP、耗时、错误类型 |
| 文件 ACL 收紧 | `Protect-PrivatePath` | 目标文件仅保留 当前用户 / SYSTEM / Administrators |
| 原子写 + 校验 | `Invoke-AtomicReplace` | 先写临时文件，`mihomo -t` 通过后才替换；失败自动还原 |

### 2.1 一次真实的 ACL 事故（已修复，保留记录）

第一版 `Protect-PrivatePath` 对一个**文件**使用了 `ContainerInherit,ObjectInherit` 继承标志。`FileSystemAccessRule` 构造函数对此抛异常，而它被 `try/catch` 吞掉，结果**当前用户的 ACE 没有加上**，ACL 里只剩 SYSTEM 与 Administrators —— 非管理员会话随即失去对该文件的读权限（`ReadAllText: Access is denied`）。

修复方式：

1. 用 `icacls <file> /reset` 恢复继承权限，确认可读；
2. 改写函数：按"文件 / 目录"分别选择继承标志，并在 `Set-Acl` 之后**回读文件**做自检，失败则返回 `$false` 而不是留一个坏 ACL。

这条记录保留在案，因为它说明：**任何降权操作都必须带可读性自检**。

## 3. 网络侧隐私

### 3.1 WebRTC 泄漏（实测发现）

用户提供的 IPPure 截图中，WebRTC 检测显示 `112.194.196.40`，即**中国联通本机公网 IP**，而此时浏览器主出口是 StarSky 的 `142.111.173.93`。

- 这是**真实的隐私泄漏**：WebRTC 的 STUN 走 UDP，未被 TCP 代理链路覆盖；
- 它**不能**用来推断任何平台已获取该 IP；
- 本工具集**不修改**浏览器指纹、时区、地理位置或 WebRTC 策略——那属于伪造设备身份的范畴，明确不做。

如需处理，属于浏览器侧的独立决定（例如限制 WebRTC 的候选地址），与本代理系统无关。

### 3.2 DNS

`NEXIP` 模式下域名由 SOCKS5 以 `ATYP=domain` 交给远端解析，本机不做明文 DNS 查询；`STARSKY`/`RAW` 模式下按各软件默认行为处理。

## 4. 明确不做的事

- 不修改系统时区、语言、地理位置、浏览器指纹或 UA 来伪装身份；
- 不关闭 Windows Defender、防火墙或任何安全功能；
- 不自动注册、登录、付费、续费；
- 不向任何第三方发送代理凭据；
- 不尝试绕过任何平台的地理限制或账号处置。

## 5. 威胁模型与建议

| 威胁 | 现状 | 建议 |
|---|---|---|
| 同机其他用户读取配置 | `%APPDATA%` 为当前用户私有 + ACE 收紧 | 保持；不要把 `proxy_v2` 放到共享目录 |
| 备份堆积导致凭据副本增多 | 快照保留 30 天 | 定期 `rollback-v2.ps1 -List` 后手工清理旧目录 |
| 日志被误发到外部 | 已脱敏 | 分享 `test-results\*.json`（不含凭据）；`.log` 亦已脱敏，但仍建议只发 JSON |
| 配置被第三方软件改写 | 已检测（`MISMATCH`） | 不要同时开启两个"系统代理管理器" |
| 密码轮换 | 未实现 | 在商家后台改密后，重新执行 `apply-v2.ps1` 并以 `-DryRun` 先验证 |

## 6. 最小权限说明

全部脚本以**当前用户**运行，不需要管理员权限：

- 系统代理在 `HKCU`，无需提权；
- 快照/还原在用户目录，无需提权；
- ACL 收紧对本人拥有的文件有效（`D:\` 下的备份目录因所有权差异可能跳过，日志会记 `WARN`）。

需要管理员权限才能做的事（修改 WFP、路由表、服务）本工具集**一律不碰**。
